Indigenous West African syllabic script of Liberia and Sierra Leone, invented by Momolu Duwalu Bukele in the 1830s.

## 🌟 Typographic Specimen

```text
ꔅꕜꕮ ꔌꔋ ꔬꔤ ꕚꕌꕮꕊ ꕒꕡ ꕉꔤ ꕉ ꕘꕌꕳ ꕉꔤ ꔱꔤ ꕮꕊ ꕆꔈꔅ
```

## ⚡ Fast Installation

### Linux & macOS (Bash)
```bash
curl -fsSL https://raw.githubusercontent.com/Open-Typography-Foundation/Vai-Liberian-Fonts-Archive/main/install.sh | bash
```

### Windows (PowerShell)
```powershell
irm https://raw.githubusercontent.com/Open-Typography-Foundation/Vai-Liberian-Fonts-Archive/main/install.ps1 | iex
```
